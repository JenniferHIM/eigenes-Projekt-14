# eigenes-Projekt-14
Mein eigenes Projekt, das aus 14 verschiedenen Aufgaben unterschiedlichen Schwierigkeitsgrades besteht.

# Challenges

## Question 1:

Level: Simple

Topic: DISTINCT
Task: Create a list of all the different (distinct) replacement costs of the films.

Question: What's the lowest replacement cost?
Answer: 9.99


## Question 2:

Level: Moderate

Topic: CASE + GROUP BY
Task: Write a query that gives an overview of how many films have replacements costs in the following cost ranges
low: 9.99 - 19.99
medium: 20.00 - 24.99
high: 25.00 - 29.99

Question: How many films have a replacement cost in the "low" group?
Answer: 514


## Question 3:

Level: Moderate
Topic: JOIN

Task: Create a list of the film titles including their title, length, and category name ordered descendingly by length. Filter the results to only the movies in the category 'Drama' or 'Sports'.

Question: In which category is the longest film and how long is it?
Answer: Sports and 184
